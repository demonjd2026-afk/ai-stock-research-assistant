Problem Statement

Why build an AI-native stock research platform on the Databricks Lakehouse?

⏰ No Governed Pipeline

Analysts rely on manual spreadsheet exports. There is no scheduled, lineage-tracked ingest of market data into a governed lakehouse.

🧩 Fragmented Tooling

Price feeds, news, sentiment, and research notes live in separate silos — no unified, queryable platform.

🤖 No Agentic Layer

Standard BI dashboards can't answer free-form queries, compare tickers, or take write actions on the user's behalf.

📰 News–Price Disconnect

Qualitative news signals are never linked to quantitative price moves in a form an analyst can query.

✅ Solution

An end-to-end Databricks Lakehouse platform ingesting 20 S&P 500 tickers daily at market close, enriching them with news sentiment via semantic RAG, and exposing a Llama 3.3 70B agentic chat interface for research, comparison, and watchlist management. Data is end-of-day — the free Massive/Polygon tier provides previous-close OHLCV, not intraday ticks.

Medallion Pipeline Deep Dive

Bronze → Silver → Gold: idempotency, data quality, and aggregation at each layer
🥉 Bronze Layer
  • Polygon REST API (api.polygon.io)
  • 20 tickers across 5 sectors
  • Idempotent MERGE upsert — replays never duplicate
  • Keys: (ticker, run_date) · (ticker, snapshot_date) · (article_id, ticker)
  • News is insert-if-absent — preserves batch_id lineage
  • Full raw_json retained; ACID writes
🥈 Silver Layer
  • ROW_NUMBER() dedup per ticker & date
  • Exchange codes normalised (XNAS → NASDAQ)
  • Derived: daily_return_pct, price_range, is_up_day
  • News deduped by article_id; sentiment normalised
  • Change Data Feed enabled on every table
  • UC grants: MODIFY (metastore v1.0)
🥇 Gold Layer
  • sector_rankings: 5 curated sectors, RANK() by market cap
  • top_movers: daily % return ranked, GAINER/LOSER
  • sentiment_summary: BULLISH/NEUTRAL/BEARISH + confidence
  • Sentiment averages joined to price data
  • Serves Agent tools + Vector Search sync task
  • Full recompute — no incremental state to drift

Lakebase + Delta CDF

OLTP write-back layer + Change Data Feed — design decisions on Free Edition
Lakebase (Design Intent)
  • Databricks-managed Postgres 17 OLTP layer
  • 8 tables created, REPLICA IDENTITY FULL on each
  • Designed for transactional write-back (watchlists, notes)
  • OAuth JWT federation unavailable on Free Edition
  • Agent write tools target main.agent.* Delta as substitute
Delta CDF (Active)
  • CDF enabled on all Silver tables
  • Captures INSERT / UPDATE / DELETE via _change_type
  • cdf_watermarks stores last version per source
  • Incremental readChangeFeed from watermark + 1
  • Watermark advances only after a successful write
Production Design Intent
  • Lakebase: watchlists + notes in Postgres (low-latency OLTP)
  • CDF: streaming propagation Silver → Gold deltas
  • Free Edition constraint → Delta-only implementation
  • Architecture is production-extensible — swap in Lakebase
  • Same CDC pattern, different transport

Technical Decisions & Learnings

Engineering trade-offs and constraints solved during implementation

API Selection

api.polygon.io chosen — api.massive.com is blocked by the Free Edition outbound filter. Same key, same endpoints; Massive rebranded from Polygon.io in Oct 2025.

Bronze Idempotency

Append-only Bronze duplicated rows on every retry. Replaced with a keyed MERGE; the batch is deduped before the merge, since one article can arrive under two tickers.

Serverless Constraints

spark.databricks.delta.schema.autoMerge.enabled is not settable on Serverless. Schema evolution uses a zero-row mergeSchema append instead.

Lineage vs Freshness

News uses insert-if-absent: a published article never changes, and updating it would rewrite the batch_id of the run that first saw it. Prices update on match — those keys include the date.

SQL Injection Surface

App tools built SQL by string concatenation, including an unescaped watchlist name. Every statement now binds named parameter markers via the Statement Execution API.

Sector Granularity

Polygon returns no sector field. Using sic_description fragmented rankings into 13 groups once all 20 tickers were active; sector is now joined from the curated registry.

Delta CDF vs Lakebase CDF

Lakebase OAuth JWT federation is unavailable on Free Edition. Delta CDF with _change_type replicates the CDC pattern natively, with a watermark table driving incremental reads.

Tool Reachability

Neither system prompt named the write tools, so save_analysis_report was never chosen and its table stayed empty. Prompts now state the routing explicitly — the tool existing is not enough.
